# TinyBASIC 言語仕様（TBI／TBC）

TapeOS の TinyBASIC の言語仕様です。実装（TBC／TBI が共有する文法）に基づきます。テストやプログラム作成の手引きとして使ってください。

## 処理系と使い方

- **TBI**（インタープリタ）：シェルで `r tbi` → `g 4000` とすると起動し、`SRC:` と聞かれるので、実行したいソースの**ファイル名**（例：`FIB.TB`）を入力します。対話式に文を打つ方式ではありません。関数は初回呼び出し時にその場でネイティブコードへコンパイルされます。
- **TBC**（コンパイラ）：`r tbc` → `g 4000`。`SRC` と `OUT` を聞かれ、ソース全体を実行ファイル（起点 0x8000）にコンパイルして FD へ書き出します。
- 言語仕様は TBI／TBC で共通です。

## プログラムの形

- プログラムは**関数定義の集合**です。行番号はありません。
- 入口は `Main` 関数です（`Main` が無いとエラー 8）。
- 例：

```
func int fib(int n)
    if n < 2 then
        return n
    endif
    return fib(n - 1) + fib(n - 2)
endfunc

func int Main()
    int a
    a = fib(15)
    print("FIB(15)=")
    print(a)
    print()
    return 0
endfunc
```

## 型と変数

- 型は `int`（16ビット符号付き）、`char`（8ビット符号なし）、`void` の3つです。関数の戻り値は単一で、再帰も使えます。
- 関数定義：`func <型> 名前(<型> 引数, ...)` … `endfunc`
- ローカル変数は、関数本体の**先頭でのみ**宣言できます。
- グローバル変数はトップレベルで宣言します。
- 配列は `dim` で宣言する**グローバル専用・1次元・定数サイズ**です。`dim int a(N)` は要素数 N で、添字は 0..N-1 です。

## 文

- 代入（文としてのみ。複合代入や `++` はありません）
- `if 条件 then` … `else` … `endif`
- `while 条件` … `endwhile`
- `repeat` … `until 条件`
- `for i = 開始 to 終了 step 増分` … `next`（step は省略可）
- `break`（ループから抜ける。`continue` はありません）
- `return [式]`
- 式文（関数呼び出しなど）

## 式と演算子

- 演算子は C 系の一式です：`+ - * / %`、`== != < <= > >=`、`&& || !`、`& | ^ ~ << >>`
- 比較は値を生みます（真＝1、偽＝0、符号付き比較）。
- `&&` と `||` は**短絡評価しません**（両辺を評価して 0/1 に正規化します）。
- 除算・剰余は C 式のゼロ方向丸めです。**ゼロ除算は 0 を返します**（暴走防止のための仕様です）。
- 数値リテラルは10進と `0x` 16進です。
- 文字列リテラルは、**関数呼び出しの引数位置でのみ**書けます（変数への代入や式の項にはなりません）。
- コメントは `/* ... */` のみです。
- 識別子とキーワードは、大小文字を区別しません。

## 組み込み関数

- `print(...)`：可変長引数。文字列リテラルはそのまま表示、値は符号付き10進で表示。引数なしは改行のみ
- `input()`：1行入力を符号付き10進として解釈して返す
- `locate(x, y)`：カーソル移動
- `cls()`：画面クリア
- `inkey()`：ノンブロッキングの1キー入力（ASCII。キーが無ければ 0）
- `stick()`：方向キーの状態。上＝1、下＝2、左＝3、右＝4、なし＝0。対応キーは上＝`8/I/W`、下＝`2/K/S`、左＝`4/J/A`、右＝`6/L/D`（大小両対応。同時に1キーしか返らないため斜めはありません）
- `vsync()`：約1フレーム待つ
- `peek(addr)`：メモリ読み（バイト、ゼロ拡張）
- `poke(addr, v)`：メモリ書き（バイト）
- `putc(c)`：1文字出力

## Scheme 呼び出し

ディスク上に `SCMCORE`（Tiny Scheme コア）がある場合に使えます。プログラム開始時に自動で読み込まれます。

- `seval("式")`：Scheme のテキストを評価し、最後の式の値を整数で返します。定義はプログラム実行中ずっと残ります
- `scall("名前", 引数...)`：名前で Scheme 手続きを呼びます（整数引数は最大8個）
- `scmerr()`：直前の呼び出しのエラーバイト（0＝正常）

受け渡せる整数は Scheme の fixnum 範囲（-16384..16383）のみです。SCMCORE が無い場合、これらの関数は 0 を返し、`scmerr()` が 251 を返します（エラーで止まることはありません）。範囲外は 252、結果を整数にできない場合は 253 です。定義だけを行いたい場合は `(begin (define ...) 0)` の形にしてください。

## エラー

エラーは `ERR LINE n Ek` と表示されます。

- 1：構文エラー
- 2：未定義の変数・関数
- 3：二重定義
- 4：引数の数・型の不一致
- 5：文字列の位置が不正
- 6：プログラムが大きすぎる
- 7：ファイルが開けない
- 8：Main がない
- 9：break がループ外
- 10：型の不一致

## 補足

- プログラムの中身を見たり書いたりするには、エディタ（MCED など）で .TB ファイルを開きます。TBI 自体に一覧表示（LIST）の機能はありません。
- サンプルは tinybasic.d88 の中にあります（FIB.TB／CALC.TB／GAME.TB／SCM.TB）。
