# 起動と IPL-ROM の動き

TapeOS を xmil コアで起動した時に、画面の向こうで何が起きているかをまとめたものです。

## 起動の流れ

1. コアが起動すると、まず **IPL-ROM**（互換 IPL）が動きます。
2. IPL はフロッピーディスク（.d88）から TapeOS を読み込みます。
3. 読み込みが終わると TapeOS のバナーが出て、シェルのプロンプト `>` が表示されます。ここから先が TapeOS です。

テープ（.cmt / .wav）から起動する場合は、IPL のメニューで CMT ブートを選びます。

## IPL のブートデバイス選択

起動時にブートデバイスの選択画面になることがあります。フロッピー、テープなどの起動元を選ぶ画面で、IPL 側の機能です（TapeOS 本体ではありません）。

## IPL のモニタ

ブートデバイス選択で **M** を選ぶと、IPL 内蔵のモニタに入ります。プロンプトは `*` です。メモリの読み書きなど、機械語モニタの機能が使えます。

注意点：

- モニタの画面では、グラフィック VRAM に残っていた内容がドット模様としてテキストに重なって見えることがあります。IPL のモニタ経路ではグラフィック画面を初期化しないためで、実害はありません。TapeOS を起動し直せば消えます（TapeOS 側は起動時に画面を初期化します）。
- モニタから抜けるには、エミュレータ側でリセットするか、コンテンツを読み直してください。

## 使っている IPL について

同梱の IPL は meister68k 氏の X1 compatible ROM（CC0）で、実機の IPL ROM とは無関係にフルスクラッチで実装された互換 IPL です。FDD／CMT／BASIC ROM 等からの起動に対応します。
