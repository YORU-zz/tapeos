# SmallC 言語仕様（SCC コンパイラ／SCI インタープリタ）

TapeOS 上の Small-C 系言語処理系の仕様です。本書の内容は実装（`smallc/src/sccore.inc`、`clib.z80`）と実装レポート（`smallc-tos.md`、`scheme-call.md`）に基づきます。一般の Small-C や C 言語の知識からの補完はしていません。

## 概要

- SmallC は、C 言語のサブセットを扱う言語処理系です。処理系は2つの形があります。
  - **SCC**（コンパイラ）：ソース全体をコンパイルし、TOSR 形式の実行ファイルを FD に書き出します。
  - **SCI**（インタープリタ）：同じソースを読み、関数単位でその場でネイティブコードへコンパイルしながら即実行します（関数単位の遅延 JIT。バイトコード方式ではありません）。
- どちらの形でも、同じソースは同じ結果を返します（全サンプルで一致を検証済みです）。
- 起動はシェルから行います。
  - SCC：`r scc` → `g 4000` とすると、`SRC:`（入力ファイル名）と `OUT:`（出力ファイル名）を聞かれます。
  - SCI：`r sci` → `g 4000` とすると、`SRC:`（入力ファイル名）だけを聞かれ、読み込んで即実行します。
- ソースは FD 上のテキストファイルです。プログラムはファイル単位で扱います（対話式に1行ずつ打つ方式ではありません）。
- SCC の出力（TOSR 実行ファイル）は、先頭に自己再配置スタブを持ち、ページ境界のアドレスに置いて実行できます。

## プログラムの形

- プログラムは、グローバル変数の宣言と関数定義の集まりです。
- 入口は小文字の `main` 関数です（`main` がないとエラーになります）。
- 関数定義は ANSI 形式と K&R 形式の両方が書けます。戻り値の型を省略すると `int` とみなされます（暗黙の int）。

```
add(a, b)
int a, b;
{
    return a + b;
}
```

- 本体のない関数宣言（プロトタイプ）も書けます。関数表へ登録だけが行われます。
- コメントは `/* … */` と `//`（行末まで）の両方が使えます。

## 型と宣言

- 型は `int`（16ビット符号付き）、`char`（8ビット符号なし）、`void` の3つです。
- ポインタは1段だけです（`int *`、`char *`）。ポインタへのポインタは書けません。
- 配列は1次元で、サイズは定数です。グローバルでもローカルでも宣言できます。

```
char buf[24];
int *sig;
```

- 宣言はブロックの先頭に書きます。変数名は関数スコープを持ち、シャドーイング（内側での同名再宣言）はできません。重複宣言はエラー（E_DUP）になります。
- グローバル変数・ローカル変数とも、初期化子は書けません。初期値は代入文で入れてください。
- `struct`／`union`／`enum`／`typedef` はありません。`float`／`double`／`long` もありません。`sizeof` もありません。

## 文の一覧

- 複合文：`{ … }`
- `if（式）文`／`if（式）文 else 文`
- `while（式）文`
- `do 文 while（式）;`
- `for（式1; 式2; 式3）文`
- `break;`：最も内側のループを抜けます
- `continue;`：ループの次の回へ進みます
- `return 式;`／`return;`
- 式文：`式;`
- 空文：`;`
- `switch` と `goto`／ラベルはありません。`switch` の代わりは `if`／`else` の連鎖で書いてください。

## 式と演算子

- 代入は式です。単純代入 `=` のほか、複合代入（`+=`、`-=` など）も使えます。代入は右結合です。
- 条件演算子 `条件 ? 式1 : 式2` が使えます。
- `&&` と `||` は短絡評価します（左辺で結果が決まれば右辺を評価しません）。
- 演算子の優先順位は、C と同じ階層です。強い順に並べます。
  - 後置 `++` `--`、関数呼び出し `()`、配列添字 `[]`
  - 単項 `-` `!` `~` `+`、前置 `++` `--`、間接参照 `*`、アドレス取得 `&`、キャスト `(int)` `(char)`
  - `*` `/` `%`
  - `+` `-`
  - `<<` `>>`
  - `<` `<=` `>` `>=`
  - `==` `!=`
  - `&`
  - `^`
  - `|`
  - `&&`
  - `||`
  - `?:`
  - 代入 `=` と複合代入
- 比較演算は値を生みます（真は1、偽は0、符号付き比較）。
- 除算・剰余は符号付きで、C と同じゼロ方向への切り捨てです。ゼロで割ると 0 が返ります（エラーにはなりません）。
- 数値リテラルは10進と `0x` 16進が書けます。
- 文字リテラルは `'a'` の形で、エスケープが使えます（例：`'\n'`）。
- 文字列リテラルは `char *` 型の値です。式の中でそのまま使えます。
- ポインタ演算は要素サイズでスケールします（`int *` は1で2バイト進みます）。ポインタ同士の差は要素数に換算されます。

## プリプロセッサ

- `#include "ファイル名"`：TOSD のディレクトリからファイルを読みます。入れ子は2段までです。
- `#define 名前 置換文字列`：オブジェクト形式のみです。最大10個まで、置換文字列は31バイトまでです。
- 関数形式マクロと、`#ifdef` などの条件付きコンパイルはありません。
- 自己参照するマクロは、展開が4段を超えるとエラー（E_PP）になります。

```
#include "cfg.h"
#define BASE 40
```

## 組み込み関数（clib）

プログラムが使うものだけがリンクされます。

- `printf(書式, ...)`：書式は `%d`（符号付き10進）、`%u`（符号なし10進）、`%c`（文字）、`%s`（文字列）、`%%` に対応します。戻り値は常に 0 です。
- `puts(文字列)`：文字列と改行を出力します。
- `putchar(c)`：1文字を出力します。
- `getchar()`：1行分の入力バッファから1文字ずつ返します。EOF の概念はありません。
- `input()`：1行入力を符号付き10進として解釈して返します。
- `locate(x, y)`：カーソルを移動します。
- `cls()`：画面をクリアします。
- `inkey()`：ノンブロッキングの1キー入力です（ASCII、なければ 0）。
- `stick()`：方向キーの状態です（上=1、下=2、左=3、右=4、なし=0）。
- `vsync()`：約1フレーム待ちます。
- `peek(addr)`：メモリを1バイト読みます（ゼロ拡張）。
- `poke(addr, v)`：メモリへ1バイト書きます。

### Scheme 呼び出し

Tiny Scheme の手続きを呼ぶ関数です。実行には、ディスク上に TOSD ファイル `SCMCORE` が必要です（プログラム開始時に自動で読み込まれます）。

- `int scmeval(char *)`：Scheme のテキストを評価し、最後の式の値を整数で返します。定義はプログラムの実行中ずっと残ります。
- `int scmcall(char *, ...)`：名前で Scheme 手続きを呼びます。整数引数は最大8個です。
- `int scmerr()`：直前の呼び出しのエラーバイトを返します（0 = 正常）。

## 変数と型・メモリモデル

- `int` は16ビット符号付きです（-32768..32767）。
- `char` は8ビット符号なしです。読み出し時はゼロ拡張され、格納時は下位8ビットに切り詰められ、演算では `int` へ昇格します。
- 関数の引数はすべて2バイトのスロットで渡されます（`char` はゼロ拡張）。戻り値は1つで、再帰も使えます。
- グローバル変数はヒープ領域に、ローカル変数は関数フレームに置かれます。
- 文字列リテラルはプログラムのイメージ内に置かれ、`char *` で指されます。文字列を書き換えることは想定していません（コピーしてから使ってください）。

## エラー

- エラーは `ERR LINE 行番号 Eコード` の形で表示されます。
- 主なコードは次のとおりです。
  - 1：構文エラー
  - 2：未定義の変数・関数
  - 3：二重定義
  - 4：引数の数・型の不一致
  - 6：プログラムが大きすぎる
  - 7：ファイルが開けない
  - 8：`main` がない

## 制限事項

- ポインタの比較は符号付きで行われます。0x8000 以上のアドレス同士の大小比較は、符号なしの大小とは一致しません（既知の制限です）。
- `printf` の戻り値は常に 0 です。`getchar` に EOF はありません。
- 複数ファイルに分けてのコンパイルはできません。単一ファイル＋ `#include` で構成してください。
- コンパイル結果のプログラムサイズには上限があります（出力イメージは最大 15,872 バイトです）。
- Scheme 呼び出しを使うプログラムは、本体＋ヒープが 0x9000 未満に収まる必要があります（SCMCORE の配置領域のため）。超える場合はエラーになります。Scheme を使わないプログラムには影響しません。
