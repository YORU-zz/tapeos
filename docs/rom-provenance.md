# ROM・フォント等の出自とライセンス

本プロジェクトの原則は「公開配布されている互換 ROM のみを使う。
実機からのダンプは使わない」です。本書は、本リポジトリに含まれる
バイナリの出自と、本プロジェクトが利用する外部バイナリの扱いを
まとめたものです。

## 本リポジトリ内のバイナリ（台帳）

本リポジトリに含まれるバイナリは、機械可読な台帳
`tools/rom-ledger.tsv`（パス＋sha256＋出自＋ライセンス）で管理して
います。CI（`tools/check-rom-ledger.py`）が「台帳に無いバイナリが
ツリーにあれば失敗」「台帳の sha256 と実物が違えば失敗」を検査
する許可リスト方式で、外部由来バイナリの紛れ込みを検出します。

台帳の内容は次のとおりです。

- `images/` のディスク／テープイメージ（13 件）：本リポジトリの
  ソースから `build.sh` で生成した配布スナップショットです
  （ライセンスは MIT）。
- `images/font.d88` 内の漢字グリフ：美咲フォント（門真なむ氏）の
  BDF から `tools/mkfont.py` で変換したものを含みます。グリフ部分
  は美咲フォントのライセンス条件に従います（同梱の `misaki.txt`
  と NOTICE を参照してください）。
- `tools/stub-template.bin`：TOSR 自己再配置スタブのテンプレート
  （本プロジェクトのソース由来、MIT）。
- `build/` 配下：`build.sh` がソースから生成する中間・最終生成物
  です。外部由来のバイナリは含みません。

## 本リポジトリに含めないもの（実行環境側）

- X1 互換 IPL ROM：meister68k 氏の X1 compatible ROM ver 0.7.3
  （CC0 1.0、実機 IPL とは無関係なフルスクラッチ実装）。姉妹
  リポジトリ YORU-zz/xmil-libretro に `rom/X1_compatible_rom.bin`
  として同梱されており、利用者が RetroArch の `system/xmil` に
  `IPLROM.X1` の名前で配置します。本リポジトリには含みません。
- X1 8×8 フォント（FNT0808.X1）：meister68k 氏の X1 互換フォント
  配布に含まれるもの（フォントデータは美咲フォント由来）。
  本リポジトリには同梱せず、利用者が配布元から入手して配置
  します。
- PC-8801 の BIOS 相当：NEC の ROM バイトは使いません。開発では
  cisc 氏の M88 疑似 BIOS を同梱する QUASI88 libretro コア
  （BSD-3）で起動しますが、疑似 BIOS のバイナリそのものは公開
  ビルドに含めません。
- CSCP EmuZ-80K／80B（MZ 用エミュレータ、武田稔也氏）：GPL の
  ため公開物には含めず、実行環境としてのみ使用します。
- S-OS 本体／CP/M 本体：公開しません。公開するのは自作の互換
  レイヤのみで、本体は利用者が各配布元から入手する前提です。
- 実機ダンプ ROM 類：一切使いません。

## 取得元の記録について

台帳の「取得元」欄には、一次資料の入手先を具体的に記録します。
雑誌の掲載リスト等を典拠とする場合は、国立国会図書館デジタル
コレクションの書誌形式「国立国会図書館デジタルコレクション：
誌名・巻号（年月）・ページ」で記録できます。

なお、掲載リストが誰でも入手できることは、その内容物
（プログラム本体等）の再配布の許可にはなりません。たとえば
S-OS 本体は、掲載リストが公開されていても本プロジェクトでは
公開しません（従来の線引きを維持します）。

## 台帳の更新方法

バイナリを新たに加える場合は、出自とライセンスを確認したうえで、
`tools/rom-ledger.tsv` に行を追加し、`docs/` の本書にも記載して
ください。出自を確認できないバイナリは追加しません。
