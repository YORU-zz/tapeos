# 技術解説02：IOCS

## 役割

IOCSは、コンソール入出力、テープ、ディスク、RAMDISKなど、機種依存の入出力を番号で呼ぶための固定ジャンプテーブルです。上層プログラムは機種を意識せず `IOCS_BASE + 3×番号` をCALLするだけでよく、この層がTapeOSの機種間互換の土台になっています。

## 実装の要点

- 形：28エントリ×3バイトのJP命令。実体は各機種のテンプレートを起動時にLDIRで所定アドレスへ複写して構築します。番号と呼出し規約は共通層で統一し、ジャンプ先の実体だけが機種別です
- レジスタ規約：原則としてBC／DE／HLは保存されます。明示された例外は3件だけです（PRTMSGはHLが進む、DELAYはHL破壊、RINITとMINIT／MDIRはHLが戻り値）。未実装エントリはキャリセットで戻るスタブです
- 基本エントリ：INKEY／KEYIN／CONOUT／PRTMSG／CRLF／GETLIN／CLRSCR／LOCATE／HEXOUT／HEX16（コンソール系）、TINF／TDAT／TWINF／TWDAT／TCTRL（テープ系）、DREAD／DWRITE（FD）、RREAD／RWRITE／RINIT（RAMDISK）などです。画面論理寸法は全機種40×25で統一しています
- 拡張IOCS（第31話対応）：X1のみ、未使用だった17／18／19／27をメインメモリ管理MINIT／MDIR／MSTORE／MFREEに割り当てました。メインメモリプール0x9000–0xCFFF（256バイト×最大64ブロック）をFAT方式で管理し、名前付き実行イメージを常駐できます。プールのディレクトリはマジック"TMEM"、FATのリンクには最上位ビットのクラス標識を使います
- シリアル追加（ロードマップ26）：X1系2ビルドは31エントリに拡張し、28 SIN／29 SOUT／30 SPOLL（RS-232Cボードが実体）を追加しました。既存28エントリの番号・アドレス・規約は不変で、契約の「追加」として扱います。あわせてBEEP（21）、RTGET（22）、BREAK（23）に本体を与えました
- MZ専用の入口：MZ両機ではRST 28HをフックしてIOCSコールへ変換するラッパーがあり、機能番号はCレジスタで渡します

## 原作との技術的差異

- テーブル配置アドレス（最重要の差異）：原作ではIOCS呼出テーブルは2000H番台に置かれる形で描かれています（展示由来文書の開示事項。作中ではMZ-80B互換テーブルをIOCS＋Monitor終了後の空き領域14A0–1FFFHに後ろから配置した経緯が第18話にあります）。再現側は機種別の固定アドレス（X1／PC-8801は0xE400、MZ両機は0xC400）です。理由：MZ-80BではTVRAM配置の都合で0xE400をRAMとして使えず、MZ-80Kでは0xE000台がI/O空間であるため、機種ごとに置ける場所が違うからです。呼出アドレスが全バイナリに焼き込まれるため最も危険な差異と位置づけ、展示では開示し、原作に沿った形への将来の変更を予告しています
- エントリの具体的な並び：原作はMZ-80BのIOCSエントリ28個を解読したことが起点です（第5話、『MZ-80B活用研究』の記事p.30から）。ただし原作の正確なエントリ一覧は作中に示されていないため、再現側の並び・名前・引数割当ては再現側の決定です。28エントリという数と固定テーブルの形は作中に合わせています
- CALLテーブル互換の維持：原作第31話の第一目標「CALLテーブルは互換性を維持する」に従い、拡張は未使用枠への割当てだけで行い、既存の番号と意味論は一切変えていません。この点は原作準拠です
- メモリ管理のFAT化：原作第31話で「メモリブロック管理はFAT16化した」と完了形で語られる唯一の要素を実装しました。ただし作中のFAT16の典拠は第27話のRAMDISK側仕様であり、再現側のRAMDISKはTOSDのままです。FAT方式のブロック管理はこのメインメモリプールが再現側で初の導入になります
- GRAM側プールの不在：作中のFATはメインメモリ256ブロックとGRAM192ブロックをクラス標識で区別する前提ですが、再現側X1のGRAMはセルアドレス方式で線形ストアに使えないため、プールはメインメモリのみです（SCEDでも確立済みの制約）
- MSTOREの同名扱い：再現側は同名格納をエラーとしました。TOSDのW（置換）とは異なる意味論です。理由：置換方式だと格納失敗時に旧イメージまで失うためで、解放はMFREEで明示する方が安全と判断しました

## 数値まとめ

- テーブル：28エントリ×3バイト＝84バイト（X1系は31エントリ＝93バイト）
- 配置：X1／PC-8801は0xE400、MZ-80B／MZ-80Kは0xC400
- 拡張IOCS本体：972バイト（X1クラシックビルドのみ）
- メインメモリプール：0x9000–0xCFFF、256バイト×最大64ブロック、同時イメージ8件
- プールのディレクトリ：8件×16バイトエントリ、FATはLE16×ブロック数
