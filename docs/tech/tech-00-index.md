# TapeOS 技術解説シリーズ 索引

TapeOS の各構成モジュールについて、実装の要点と、原作小説との技術的差異を根拠付きで解説するシリーズです。構成は古典的な OS 解説書（MINIX 本など）の型に倣い、導入にあたる土台の章から構成モジュール別の章へ進みます。各文書は「役割と設計」「実装の要点」「原作との技術的差異」「数値まとめ」の構成で、章の中でも設計（なぜそうしたか）を実装の前に置きます。差異には原作側の根拠（話数）と再現側の理由を必ず添えています。

- tech-01-shell.md — シェル／モニタ：起動、コマンドディスパッチ、常駐配置とサイズ上限の話です
- tech-02-iocs.md — IOCS：28エントリの固定コール表、拡張IOCSとシリアル追加、配置アドレスの差異です
- tech-03-filesystem.md — TOSDファイルシステムとドライブ層：FD／RAMDISK／EMM、追記型確保の形式です
- tech-04-tape.md — テープ層：HuBASIC互換の論理形式、機種別物理層、4800bps化とWAV相互運用です
- tech-05-tinybasic.md — TinyBASIC：共有フロントエンドを持つコンパイラと関数単位遅延JITインタープリタです
- tech-06-smallc.md — SmallC：CサブセットのコンパイラとJIT、clibとTOS適応の記録です
- tech-07-tiny-scheme.md — Tiny Scheme：テープ先頭ローダーの単体版と、言語へ埋め込むSCMCOREです
- tech-08-tools.md — ツール群：エディタ2本、アセンブラ2本、逆アセンブラの系譜と共存です
- tech-09-debugger.md — デバッガ：常駐スタブ、単独デバッガ、二層リモートデバッガの3形態です
- tech-10-serial.md — シリアル／RS-232C：i8251ボードのコア側モデルとPTYブリッジです
- tech-11-kanji-font.md — 漢字・フォント層：美咲フォント由来のグリフ供給とKANJI表示です
- tech-12-memory-map.md — X1のメモリマップ：常駐配置の一覧と簡易図、機種差の注記です

読み方の目安：全体像は01→02→03→04の順が土台で、言語系（05〜07）とツール系（08）は独立に読めます。09と10は互いに関連します。
