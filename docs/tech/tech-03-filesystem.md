# 技術解説03：TOSDファイルシステムとドライブ層

## 役割と設計

TOSD は、TapeOS の全ドライブに共通するファイル規約です。シェルの F（一覧）／R（読込）／W（保存）が扱うファイルの置き方を定め、FD と RAMDISK という性格の違う媒体を、同じ見かけで使えるようにします。

設計の中心は「単純さ」です。ディレクトリはドライブに1つだけの256バイトセクタで、エントリは最大15件の固定長です。割当ては連続・追記のみで、断片化の回収機構を持ちません。削除コマンドもシェルには無く、削除は上書き時の解放としてだけ発生します。サブディレクトリもありません。8ビット機のモニタ環境で、形式の検証と実装の両方が小さく収まることを優先した設計です。

もう一つの設計判断は、ドライブ層の単位統一です。FD の単位は「レコード」、RAMDISK の単位は「ブロック」と呼びますが、どちらも256バイトで、IOCS の DREAD／DWRITE（FD）と RREAD／RWRITE（RAMDISK）が同じ単位・同じ引数作法で呼べます。ファイル層はこの単位の上に乗り、ドライブ切替（シェルの U コマンド）だけで媒体を入れ替えられます。

## 実装の要点

- ディレクトリセクタ（256バイト）：先頭にマジック "TOSD"、形式バージョン（現行1）、+6に次の空き単位（LE16。初期値は FD＝48、RAMDISK＝1）、+16から16バイト×15件のエントリです
- エントリ（16バイト）：名前10バイト（空白詰め、先頭バイト 0x00 が空き）、開始単位（LE16）、サイズ（LE16）、ロードアドレス（LE16）です。拡張子や属性のフィールドはありません
- 命名：最大10文字、格納時に大文字化されます（入力は大小不問）。10文字超と空の名前はエラーです
- 割当て：必要単位数を切り上げ、次空きポインタから連続確保してポインタを進めます。上書き時は、新データが旧領域に収まれば開始位置不変で再利用し、入らなければ旧エントリを解放して末尾へ追加します。解放された領域は再利用されません
- ロードアドレス：`W name addr len` は書込み開始アドレスを記録し、`R name` は記録されたアドレスへそのまま転送します（再配置フックなし。リロケータブルなプログラムは TOSR の自己再配置が担います）
- FD の配置：レコード番号は ((track×2＋side)＜＜4)｜(sector−1) で、0〜31がブート／システム領域、32がディレクトリ、48〜1279がファイルデータ領域です（最大1280レコード＝320KB）
- RAMDISK の論理仕様：256バイトブロック、最大256ブロック＝64KB で、ブロック0がディレクトリです。RINIT は要求を機種上限にクランプし、確定値を返します
- RAMDISK の裏付け：X1 では EMM（ポート 0x0D00〜0x0D03、アドレスレジスタは L→M→H の順に書く）に置き、メインメモリを消費しません。EMM デバイス自体は1MBですが、運用上限は64KBにかけてあります。他機種は実 RAM の2セグメント構成で、上限は MZ-80B＝96ブロック、MZ-80K＝80ブロック、PC-8801＝68ブロックです（EDAS ゾーンやワークページを避けた残りです）
- EMM の他用途：SCED のテキストバッファ（0x10000〜、24KB×2）と MCED のキルバッファ（0x1C000、8KB）が、RAMDISK 領域と重ならない位置に割り当てられています

## 原作との技術的差異

- TOSD のバイトレイアウト自体：作中に記述はありません（interface-spec §3 の冒頭が明記しています）。作中にあるのは RAMDISK の IOCS 仕様と、FD 対応版の呼称のみで、ディレクトリ形式やエントリ構造はすべて再現側の形式です
- RAMDISK の仕様：256バイトブロック・最大64KB は第19話、動的な拡張／縮小（再構成）は第47話に基づいており、この点は原作準拠です。再現側もシェルの I コマンドでブロック数を指定して再構成できます
- 他機種の RAMDISK 容量：作中の64KB は EMM という別メモリの裏付けあっての値です（interface-spec §2.4）。EMM の無い MZ 両機と PC-8801 では実 RAM の空きに収まる範囲へクランプされ、確定値が正直に返ります。これは機種側の事情による差異です
- FD 対応版の呼称：作中の FD 対応版は OUROBO/DOS と呼ばれます。再現側のシェルは TapeOS の名のまま FD に対応しており、世代による改名は再現していません

## 数値まとめ

- ディレクトリ：256バイト×1（ドライブごと）、エントリ16バイト×最大15件
- ファイル名：最大10文字（空白詰め、大文字化）
- FD：最大1280レコード（320KB）、データ開始レコード48
- RAMDISK：ブロック256バイト、最大256ブロック＝64KB（X1／EMM）、他機種上限は96／80／68ブロック
- EMM：デバイス1MB、TapeOS の割当ては 0x00000〜0x1BFFF までを使用
