# シェルの最低限コマンド

TapeOS のシェル（プロンプト `>`）で最初に必要になるコマンドだけをまとめたものです。全コマンドはシェルの詳細ヘルプ（ディスク上の HELP プログラム）にも載っています。各コマンドの引数や注意点まで含めた詳細は「シェルコマンド リファレンス」（docs/shell-command-reference.md）にあります。

## プログラムの実行（基本の型）

ディスク上のプログラムは、読み込んでから実行します。

```
r 名前
g 4000
```

- `r 名前`：ドライブからプログラムを読み込みます（例：`r tbi` で TinyBASIC インタープリタ）。
- `g 4000`：読み込んだプログラムを実行します。多くのプログラムは 0x4000 配置です。

## よく使うコマンド

- `f`：現在のドライブのファイル一覧を表示します。
- `r 名前`：ドライブからファイルを読み込みます。
- `g [アドレス]`：プログラムを実行（CALL）します。アドレス省略時はデモノートが表示されます。
- `u [ドライブ]`：ドライブを切り替えます（0=FD、1=RAMDISK）。
- `t [名前]`：テープから読み込みます。
- `c`：日時を表示します。
- `v`：バージョンを表示します。
- `h`：簡易ヘルプを表示します。詳細ヘルプはディスクプログラムの HELP（`r help` → `g 4000`）です。
- `k` コマンド相当の漢字表示は、ディスクプログラムの KANJI（`r kanji` → `g 4000`）に移っています。

## その他のコマンド（詳細ヘルプより）

- `d [アドレス]`：メモリを 128 バイト表示（ダンプ）
- `e アドレス`：バイトの検査／変更
- `m アドレス バイト...`：バイト列の書き込み
- `w 名前 アドレス 長さ`：ドライブへ保存
- `s アドレス 長さ [名前]`：テープへ保存（新規）
- `a アドレス 長さ [名前]`：テープへ追加保存
- `i [ブロック数]`：RAMDISK の初期化（ブロック数は16進）
- `n`：メモリ情報
- `x`：常駐デバッグスタブ

## 例：TinyBASIC を使う

tinybasic.d88 で起動したら：

```
r tbi
g 4000
```

`SRC:` と聞かれたら、実行したいソースの**ファイル名**（例：`FIB.TB`）を入力します。TBI は対話式に文を打つ方式ではなく、ファイルを実行する方式です。プログラムの中身を見たり書いたりするには、エディタ（MCED など）で .TB ファイルを開きます。
