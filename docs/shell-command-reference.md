# シェルコマンド リファレンス

TapeOS シェルの全コマンドの詳細です。まず最低限だけ知りたい場合は「シェルの最低限コマンド」（docs/shell-commands.md）を見てください。本書の内容はシェルの実装（ソースコード）に基づきます。

## 共通の約束

- コマンドは1文字で、大文字・小文字を区別しません。
- 数値はすべて16進数です（アドレス、長さ、ブロック数）。
- 空行（Enter のみ）では何も起きず、プロンプトに戻ります。
- 存在しないコマンドや、引数の解釈に失敗した場合はエラーメッセージが出て、プロンプトに戻ります。
- ファイル名は、ディスク上の名前（例：`TBI`、`FIB.TB`）で指定します。

## H：ヘルプ

- 形式：`h`
- シェル常駐の簡易ヘルプを表示します。詳細なヘルプは、ディスクプログラムの HELP（`r help` → `g 4000`）にあります。

## V：バージョン

- 形式：`v`
- シェルのバージョン表示です。

## C：日時

- 形式：`c`
- RTC（リアルタイムクロック）から現在の日時を読み取って表示します。

## F：ファイル一覧

- 形式：`f`
- 現在のドライブ（`u` で選択中）のファイル一覧を表示します。各行に、名前・サイズ・ロードアドレスが出ます。
- 例：tinybasic.d88 で起動すると `TBI`、`FIB.TB` などが並びます。

## R：ファイルの読み込み

- 形式：`r 名前`
- 現在のドライブからファイルを読み込みます。読み込み先は、そのファイルに記録されたロードアドレスです（`w` で保存した時に決まります）。
- 例：`r tbi`（TinyBASIC インタープリタの読み込み。実行は続けて `g 4000`）

## W：ファイルの保存

- 形式：`w 名前 アドレス 長さ`
- メモリの アドレス から 長さ バイトを、名前 を付けて現在のドライブへ保存します。開始アドレスが、そのファイルのロードアドレスとして記録されます（`r` はそこへ読み込みます）。

## U：ドライブ選択

- 形式：`u [ドライブ]`
- `f`／`r`／`w` の対象ドライブを切り替えます。`0`＝FD（起動時の既定）、`1`＝RAMDISK。
- 引数を省略すると、現在の選択を表示します。
- RAMDISK が未設定（`i` 未実行）の状態で `u 1` を選ぶとエラーになります。

## I：RAMDISK の初期化

- 形式：`i [ブロック数]`
- RAMDISK を初期化（再設定）します。ブロック数は16進で、1ブロック＝256バイト、最大 100h ブロック（64KB）です。EMM が必要です。
- 初期化すると RAMDISK はフォーマットされ、以前の内容は失われます。
- 引数を省略すると、現在の設定を表示します。

## T：テープからの読み込み

- 形式：`t [名前]`
- テープからプログラムを読み込みます。読み込み先は、テープの情報ブロックに記録されたロードアドレスです。
- 名前を省略すると、テープの先頭のプログラムを読み込みます。名前を指定すると、情報ブロックを先頭から走査し、一致しないプログラムを読み飛ばして、一致したものを読み込みます。

## S：テープへの保存（新規）

- 形式：`s アドレス 長さ [名前]`
- メモリの アドレス から 長さ バイトをテープへ保存します。新規作成で、テープの内容は置き換わります（最初に EJECT 相当の動作が入ります）。
- 名前を省略すると `TAPEOS` になります。

## A：テープへの追加保存

- 形式：`a アドレス 長さ [名前]`
- 現在のテープ位置へ、プログラムを追加で保存します（EJECT はしません）。
- 注意：エミュレータ（パッチ版 xmil コア）では、`s`／`a` の直後に続けて記録した場合に追加として扱われます。再生・巻き戻し・イジェクトを挟むと連続性が切れ、次の `a` は新規テープとして始まります。

## D：メモリダンプ

- 形式：`d [アドレス]`
- 128バイトを表示します（1行＝16バイトの16進表示＋文字表示。表示できない文字は `.` になります）。
- アドレスを省略すると、前回の続きから表示します。

## E：バイトの検査・変更

- 形式：`e アドレス`
- 対話式に1バイトずつ検査・変更します。各バイトで `アドレス: 現在の値` と表示されるので：
  - 16進のバイト値を入力すると、書き換えて次へ進みます
  - 空行（Enter のみ）では、書き換えずに次へ進みます
  - `.` を入力すると終了します
  - それ以外の入力では、同じアドレスを聞き直します

## M：バイト列の書き込み

- 形式：`m アドレス バイト [バイト ...]`
- アドレス から、指定したバイト列を順に書き込みます。
- 例：`m 8000 3e 01 c9`（0x8000 から 3E 01 C9 を書く）

## G：実行

- 形式：`g [アドレス]`
- 指定アドレスのルーチンを呼び出します。ルーチンが RET で戻ると、シェルに帰ってきます。
- アドレスを省略すると、内蔵のデモ（案内文の表示）が動きます。
- `j` も同じコマンドです（別名）。

## N：メモリイメージ（常駐イメージの管理）

- 形式：`n`／`n i [ブロック数]`／`n s 名前 アドレス 長さ`／`n r 名前`／`n f 名前`
- メモリ上のプールに、プログラムを「イメージ」として名前付きで保持・再利用するための仕組みです。
  - `n`：常駐イメージの一覧と空きブロック数を表示します
  - `n i [ブロック数]`：プールを初期化します（ブロック数は16進。省略時は最大値。再フォーマットされます）
  - `n s 名前 アドレス 長さ`：メモリの範囲を名前付きイメージとして格納します
  - `n r 名前`：イメージを記録されたアドレスへ読み込んで実行します（RET でシェルへ戻ります）
  - `n f 名前`：イメージを解放します

## X：常駐デバッグスタブ

- 形式：`x`
- 常駐デバッグスタブ（リモートデバッガの下層）に入ります。使い方の詳細は remote-debug-protocol.md を参照してください。ディスク版のデバッガは RDBG（`r rdbg` → `g 4000`）です。

## ディスクプログラムとして提供されるもの

- HELP：詳細ヘルプ（`r help` → `g 4000`）
- KANJI：漢字表示関連（`r kanji` → `g 4000`）
